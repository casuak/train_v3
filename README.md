# 逐温线 · The Wandering Line

一款关于铁路迁徙的 2D 列车聚落经营游戏。带领六名旅人，从霜河机务段出发，经由煤脊山线或河谷平原，抵达白桦避风港。

**首个可玩版本：v0.1.0。仅面向 PC 网页端键盘与鼠标，不设计手机操作。**

## 启动

需要 Node.js 22.12+ 或 24，推荐 Node.js 24。

```bash
npm ci
npm run dev
```

按终端显示的地址打开游戏。若当前运行环境限制网卡枚举，可仅监听本机：

安装时会自动从 `art/packed/` 无损还原两张图片素材并验证校验和。若显式禁用了安装脚本，启动前执行 `npm run assets`。

```bash
npm run dev -- --host 127.0.0.1
```

## 构建与独立游玩文件

```bash
npm test
npm run build
npm run package
```

- `dist/` 是可部署到静态托管服务的网页。
- `dist/train-v0.1.html` 是包含程序、样式和生成素材的单文件版本，下载后可以用 PC 浏览器打开，无需联网加载素材。
- 普通网页构建使用 `npm run preview -- --host 127.0.0.1` 预览。
- 单文件版本不需要安装 Node.js。浏览器需支持 WebGL 2；建议 1440×900 或更大的窗口。

## 开始你的第一趟迁徙

1. 点击“开始迁徙”，在铁路地图中选择 **芦湾农场**，再点击“驶向芦湾农场”。
2. 旅人会自动做饭、制作维修零件、搬运、进食和休息。可在“工作安排”调整 0—4 级优先级。
3. 右键炉灶或工作台设置制作清单；先选中旅人，再右键设施可以安排强制工作。
4. 登车警报出现时游戏暂停。可点击“征召并部署车顶”，然后恢复 1× 执行；也可单独征召，右键移动或指定攻击。
5. 击退敌人后解除征召，让旅人回到日常生活。到站后在铁路地图选择下一站，并按需交易补给。
6. 南线建议经过 **芦湾农场 → 石桥集市 → 南岭隧道 → 白桦避风港**。北线可以在旧编组站修复并挂接第四节车厢。

## PC 操作

| 操作 | 输入 |
| --- | --- |
| 选择人物/设施、点击界面 | 鼠标左键 |
| 多选人物 | 空地左键框选；Shift + 点击 |
| 制作设置、强制工作 | 鼠标右键目标 |
| 征召移动/攻击 | 选人后右键地面/敌人 |
| 平移视角 | 鼠标中键或右键拖拽 |
| 缩放 | 鼠标滚轮，或右上角缩放按钮 |
| 暂停/恢复 | 空格，或右下角暂停按钮 |
| 1× / 2× / 3× | 数字 1/2/3，或右下角对应按钮 |
| 征召/解除征召 | R，或人物面板按钮 |
| 车内/车顶 | Tab，或右上角楼层按钮 |
| 旋转建造蓝图 | R，或建造提示条中的旋转按钮 |
| 关闭面板/取消 | Esc，或关闭按钮 |

右下角始终有四个速度按钮：**暂停、1×、2×、3×**。主要玩法可以只用鼠标完成。暂停时可以下达指令；页面进入后台会自动暂停；输入框内不会触发游戏快捷键。

## 当前可玩内容

- 1 台机车、3 节初始车厢、6 名具有不同技能的旅人。
- 车内/车顶双层导航、梯口连接、车厢间通行；友军可在狭窄走廊错身，设施与床位互斥预约。
- 饱食度、精力、生命；自动进食、睡觉、包扎与常规工作。
- 工作优先级、强制任务、生产清单（指定次数/保持库存/持续制作）。
- 真实物资预约、取料、在途货物、成品入库；中断任务保留搬运物资。
- 炉灶、工作台、床、储柜、供暖器、车顶掩体的建造与拆除；损坏维修。
- 征召、移动、近战/远程攻击；敌人优先攻击车顶目标，破坏舱门后进入车内。
- 7 个铁路节点、两条分支路线、燃煤消耗、温度、寒潮封线、补给交易与车厢扩张。
- 胜负流程、操作指南、旅程日志、合成音效与声音开关。
- IndexedDB 手动/自动存档、JSON 导出导入；自动存档每 60 秒触发。
- 两张图片生成素材：人物/设施图集与北境背景；人物使用 Three.js Bone 分件骨骼，轮轴使用旋转骨骼。

## 版本边界与验收状态

此版本是可运行的完整短途迁徙闭环。地图、事件与配方采用小规模固定内容；人物美术目前采用侧向镜像，动作以轻量骨骼复用为主；倒地按本局阵亡处理。长期人物关系、完整四季、多年世界衰退、开放世界步行探索不在本版范围。

自动化验收覆盖模拟规则、南北两条完整旅程、PC 界面交互和 IndexedDB 存档。**当前交付环境的浏览器安全策略禁止访问本地服务与文件，因此未完成真实浏览器画面、GPU 性能及人工试玩验收。**该限制不等同于已通过浏览器端到端测试；详细记录见 [验收记录](docs/acceptance-v0.1.md)。

本地存档归当前浏览器管理。更换浏览器或清理站点数据前，可在“旅程菜单”导出 JSON 文件备份；单文件版本也建议定期导出。

## 工程结构

| 路径 | 职责 |
| --- | --- |
| `src/sim/` | 游戏状态、内容定义、固定步模拟、调度与导航 |
| `src/render/` | Three.js 场景、图集、骨骼、相机与拾取 |
| `src/ui/` | HTML/CSS 操作界面、输入与音效 |
| `src/save/` | 存档序列化、校验、IndexedDB |
| `tests/` | 规则、完整旅程、DOM 交互与存档回归 |
| `public/assets/` | 图片生成的运行素材 |
| `art/generation.md` | 素材生成提示与绑定说明 |
| `docs/` | 原始设计、开发规划、PC 规范与验收记录 |

工程使用 TypeScript strict、Three.js、Vite、Vitest。模拟固定 20 Hz，DOM 管理界面约 5 Hz 更新；画面跟随浏览器刷新。测试中的 DOM 环境不包含真实 WebGL 渲染器。

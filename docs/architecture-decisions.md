# v0.1 工程决策

- **PC 优先**：鼠标完成全部必需操作；空格和 1/2/3 提供快捷键；右下角四个速度按钮固定可见。
- **模拟与显示分离**：权威状态为普通 TypeScript 对象；存档不包含 Three.js 对象或 DOM。
- **20 Hz 固定步**：倍速改变每帧处理的步数；暂停冻结人物需求、生产、战斗、行程和骨骼动作。
- **二维画面**：Three.js 正交投影＋透明贴图平面；室内和车顶通过层标识区分，同时投影到上下两条可见水平线。
- **导航**：每层只有一条横向通道，使用广度优先最短路；跨层连接纳入邻接图。后续扩大地图可替换为 A*。友军允许在通道错身，敌我接触阻挡。
- **岗位预约**：床位与工作台互斥；物品按数量预约；取料后转为任务携带物。取消任务时掉落携带物，完成后输出物转为携带物并入库。
- **管理界面**：采用 TypeScript＋原生 DOM 事件委托；HUD 以增量更新保留按钮节点，避免状态刷新中断鼠标点击与焦点。绘制窗口独立由 Three.js 管理。
- **动画**：轻量 Three.js Bone 层级，刚性分件；不用外部收费骨骼运行时。方向先采用左右镜像。
- **存档**：IndexedDB；不可用或写入事务中断时尝试 localStorage。内部记录带更新时间，按槽顺序保存，读取较新的副本；兼容旧版未封装记录，JSON 导出格式为 v2；v1 存档读入时重新横向排布设施并归还任务携带物。导入前校验版本、数据形状、数量边界、标识和内容类型。
- **交付**：普通静态构建＋内嵌全部素材的独立 HTML；无在线 API、账号系统或分析追踪依赖。
- **验证边界**：模拟、完整旅程和 DOM/存档测试通过不代表 WebGL 画面或性能通过。交付环境阻止本地浏览器导航，因此单独记录真实浏览器验收缺口。

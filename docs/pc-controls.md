# PC 网页端操作约定

本游戏仅按照 PC 网页端键盘与鼠标游玩设计，不考虑手机游玩或触控适配。大部分操作只需要鼠标，键盘作为快捷操作。

- 鼠标左键：选择人物、设施或界面项目；空地拖拽框选人物。
- 鼠标右键：工作台制作设置；选中人物后的强制行动；征召状态下的移动和攻击。
- 鼠标滚轮：缩放；鼠标中键或右键拖拽空白区域：平移。
- 空格：暂停/恢复上一次非零倍速；输入框内不触发游戏快捷键。
- 右下角固定四个按钮：暂停、1 倍速、2 倍速、3 倍速。选中的按钮明确高亮。
- 数字 1/2/3：设置对应倍速；R 征召/解除征召；Tab 切换车内/车顶；Escape 关闭菜单/取消选择。
- 所有必需功能均有可点击按钮：征召、楼层切换、生产设置、存档、路线、工作安排。
- 暂停时可以安排工作、生产、建造、路线与战术命令；恢复后执行。
- 页面切到后台或窗口失去焦点自动暂停。打开帮助、旅程菜单和新局确认时暂停，期间快捷键不恢复时间；一般管理面板不隐式暂停。
- 桌面推荐 1440×900，最低建议 1024×720；小屏显示桌面游玩提示。

- 长按空格或 R 不重复切换状态；Ctrl / Command / Alt 组合键留给浏览器。
- 指针取消、失焦和 Esc 会结束当前拖拽，避免误发移动命令。

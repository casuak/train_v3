# 首个可玩版本验收记录

## 实现范围

实现 PC 网页端鼠标为主的操作；空格暂停；右下角四个按钮分别为暂停、1×、2×、3×。首版包含六人列车经营、双层空间、生产建造、征召登车战、七节点铁路旅程、交易扩张与存读档。

## 已验证

- TypeScript strict 类型检查与 Vite 生产构建。
- 32 项自动化测试：16 项模拟/导航/战斗/存档数据测试、2 条完整旅程、10 项 DOM 交互测试、2 项存储测试、2 项时钟测试。
- 南线使用正常初始物资和真实武器，通过调度、征召部署与交易抵达白桦避风港。
- 北线修复挂接第四节车厢，在寒潮封线前完成迁徙。
- 两人争夺最后一份食物时只允许一份预约；中断工作后携带物资保留；在制品计入生产目标。
- 跨车厢与跨层导航；敌人破门入侵；车顶防守；不同楼层不直接互相造成伤害。
- 按钮、右键菜单、工作表、制作数量、建造蓝图、路线出发、征召部署和输入框快捷键屏蔽。
- 1/2/3 倍速在相同模拟时间得到相同人物和物资状态；暂停不消耗需求，也不在恢复时补算暂停时长。
- IndexedDB 的手动/自动槽位独立；JSON 导入拒绝结构损坏和非法字段。
- 构建独立 HTML，把脚本、样式与两张生成素材内嵌；普通静态构建保留在 dist。

完整旅程测试采用自动脚本下达正常玩家指令，不提升人物生命、武器或额外发放物资。这些测试证明对应规则可以完成闭环，不代替人类体验平衡测试。

## 当前环境无法完成的验收

真实浏览器尝试打开本地服务时收到访问阻止；访问同步目录中的本地 HTML 时，浏览器安全策略拒绝 file 协议。已停止该浏览器路径，没有绕过限制。

因此以下内容尚未确认：

- 实际 WebGL 画面、字体、素材遮挡和鼠标拾取位置的视觉验收。
- 真实 GPU 帧率与不同 PC 分辨率下的操作体验。
- 通过真实浏览器完整游玩首局，以及浏览器中直接双击单文件版本的最终检查。

DOM 交互测试使用 jsdom 和渲染接口替身；存储测试使用 IndexedDB 兼容实现。它们不是 Playwright 浏览器端到端测试，也不用于声称已验证 60 FPS。

## 建议的人工试玩步骤

1. PC 浏览器打开独立 HTML 或本地开发服务，检查六张人物卡、列车、设施、背景和右下四按钮。
2. 开始迁徙，选择南线；分别测试暂停、1×、2×、3×与空格。
3. 右键炉灶设定制作数量；选择旅人右键工作台强制执行；检查工作表优先级。
4. 放置一个供暖器或床，观察取料与施工。
5. 袭击发生时部署车顶，检查征召移动、攻击和解除征召。另开一局允许敌人破门进入车内。
6. 在生产中和战斗中分别保存/读取，检查物资、目标、楼层和进度。
7. 到站补给，完成南线；另行验证北线车厢扩张。

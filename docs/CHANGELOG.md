# 更新记录

## v0.1.1

- 同步相机矩阵，修复连续平移、缩放与聚焦后的拾取误差。
- 保留 HUD 按钮节点，状态更新不再中断点击和键盘焦点。
- 修复长按快捷键反复切换；忽略浏览器组合键；补齐失焦和指针取消处理。
- 读档、导入和新局重置建造、选中、楼层与动画状态，并释放旧人物资源。
- 存档记录增加更新时间、同槽顺序写入和事务中断回退，避免读取旧的备用副本。
- 保留 v0.1.0 浏览器存档和 JSON 兼容性；拒绝坐标、标识、动作、线路等损坏数据。
- 测试从 32 项增加到 50 项。相机测试使用真实 Three.js 数学对象和绘制替身，不代表真实 WebGL 验收。
- 独立 HTML 文件名与游戏内版本号跟随 package.json。

## v0.1.0

- 完成 PC 网页端首个可玩版本《逐温线》。
- 加入鼠标主导操作、空格暂停和右下角暂停/1×/2×/3×四按钮。
- 实现列车双层场景、自动生活、工作与生产、建造维修、征召登车战。
- 实现七节点铁路迁徙、分支路线、寒潮、交易和第四节车厢扩张。
- 使用生成图集与环境背景，人物和轮轴采用轻量骨骼动画。
- 支持自动/手动存档、JSON 导入导出与独立 HTML 打包。
- 加入固定步进、资源预约、任务中断、完整旅程和界面交互的自动化回归。
- 实际浏览器画面与 GPU 性能验收受交付环境访问策略限制，详见验收记录。

# v0.2.0 · 横版侧视修正

- 整体改为真正的横版 2D 正侧视剖面，车内和车顶同屏可见；重做车厢、舷梯、车底、轨道与机车布局。
- 新生成侧面角色分件、家具、机车图集与平视雪山背景，保留 Bone 人物和轮轴动画。
- 导航改为各层左右行走，梯口换层；家具靠后墙摆放，掩体阻挡并可被敌人破坏。
- 点击根据画面高度识别楼层，支持同屏跨层选择、框选和右键命令；R 翻转家具方向。
- v1 存档转换为 v2，保留人物、设施、制作清单、资源和旅程，归还在途资源后重派旧任务。
- 新增侧视投影、拾取、横向导航、掩体破坏和旧存档迁移回归测试。

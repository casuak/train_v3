# v0.2.0 横版侧视验收

## 已验证

- 正交坐标：车内和车顶对应不同屏幕高度，缩放/平移后拾取稳定。
- 同屏拾取：人物、工作台和不同楼层的空地能准确识别。
- 导航：仅横向移动，跨车厢和舷梯换层可达，家具不封死通道。
- 建造：左右翻转不改变占地，禁止把家具建在连接器或错误楼层。
- 登车战：敌人破坏车顶掩体与舱门后可以进入车内。
- 生存、生产、征召、完整南北旅程、扩张、存档回归。
- 旧存档：同列设施重新分配槽位，物资与旅程保留，旧路径清理；新格式保存后可再读取。

## 验证范围

57 项 Vitest 测试，包含真实 Three.js 相机计算和 DOM 交互；渲染器在相机单元测试中替换为模拟对象。TypeScript strict 与 Vite 构建独立检查。

本次预览服务未能启动（托管预览进程不可用），因此没有浏览器截图或实际 GPU 帧率结论。未使用其他路径绕过该环境限制。
